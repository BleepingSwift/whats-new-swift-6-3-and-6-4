# WhatsNewSwift63And64

Sample code demonstrating Swift shipped twice this cycle: 6.3 in the spring and 6.4 alongside Xcode 27 at WWDC. Module selectors, async defer, and task cancellation shields are the three changes you'll actually use..

> This project accompanies the article: [What's New in Swift 6.3 and 6.4](https://bleepingswift.com/blog/whats-new-swift-6-3-and-6-4)

## Requirements

- Xcode 27.0+
- iOS 26.0+
- Swift 6.0

## Getting Started

1. Clone this repository
2. Run `xcodegen generate` (requires [XcodeGen](https://github.com/yonaskolb/XcodeGen))
3. Open `WhatsNewSwift63And64.xcodeproj`
4. Build and run
